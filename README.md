# 🌸 Digital Wellbeing Dashboard

An interactive Power BI dashboard built using a self-created dataset to analyze daily digital habits and wellbeing metrics.

## 📌 Project Overview

This project transforms raw digital wellbeing data into meaningful insights through interactive visualizations and KPI cards.

The dashboard helps users monitor:

* 📱 Screen time trends
* 🌙 Sleep patterns
* 🎯 Productivity scores
* 🔔 Notification frequency
* 🧘 Focus mode usage
* 🔋 Battery usage
* 📊 App usage distribution

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization

## 📂 Dataset

The dataset used in this project was created from scratch to simulate real-world digital wellbeing behavior.


## 💡 Key Features

* Interactive KPI cards
* Dynamic date slicer
* Trend analysis charts
* Donut chart for app usage distribution
* Battery usage gauge
* Personalized wellbeing insights

## 🚀 Project Outcome

This dashboard demonstrates an end-to-end analytics workflow, from data creation and transformation to visualization and storytelling.
